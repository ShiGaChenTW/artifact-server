Document widths

Narrow 560px: short reading lines. Original 780px: report-sized content without forcing paper dimensions on arbitrary artifacts. Wide 1040px: tables and code with a fixed desktop cap. Smaller viewports reflow to available width less 48px surround. Zoom ranges from 40% to 200%, capped earlier when rendered width reaches 1040px; width and fit controls cannot bypass the cap. Fit resets pan and scale. Top translation is clamped at zero to retain 24px surround.

Ruling: the explicit maximum visible width takes precedence over allowing 200% at every base width. At 780px the visual zoom cap is 133%, at 1040px 100%; on narrow viewports 200% remains available. This prevents the maximum-width promise being bypassed by zoom.
